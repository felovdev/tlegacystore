# TLegacyStore

Каталог архивных iOS-приложений и игр.

Каталог архивных iOS-приложений и игр.

**Сайт:** https://felovdev.github.io/tlegacystore/

## Как пользоваться

- Используй строку поиска, чтобы найти приложение по названию.
- Выбирай фильтры, чтобы сузить список по версии iOS, году, типу приложения и отметкам Decrypted или Cracked.
- Нажми на карточку приложения, чтобы открыть страницу с описанием, доступными IPA-файлами и ссылкой на оригинальную запись Internet Archive.
- Нажми на имя IPA-файла, чтобы открыть его страницу загрузки в Internet Archive.
- На странице приложения можно читать комментарии и оставлять свои, если сервис комментариев доступен.

## Комментарии

- Имя: до 40 символов.
- Сообщение: до 500 символов.
- Между отправками комментариев действует пауза 20 секунд.
- Комментарии публикуются и отображаются на странице соответствующего приложения.

## Источники и точность данных

Каталог получает записи и метаданные из Internet Archive. Дополнительные архивы доступны в разделе «Другие архивы».

Версия iOS, категория приложения и отметки Decrypted/Cracked могут определяться автоматически по описанию и другим метаданным. Это ориентировочные сведения, а не проверка IPA-файла.

Каталог не размещает файлы самостоятельно: доступность файлов зависит от внешнего архива. Перед загрузкой и использованием файлов самостоятельно проверяй их безопасность и соблюдай применимые права и условия распространения.
